# Founder Repurpose

One piece of long-form content usually has three to five posts hiding
inside it. The failure mode is turning it into one post that's just a
summary, which reads thin next to the original.

## Method

1. Read or watch the source material fully before drafting anything.
2. Pull out every distinct claim, story, number, or moment that could
   carry a post on its own, not just the headline point.
3. For each one, hand it to the same method as founder-post: real angle,
   matching hook formula, checked for AI tells. Each post has to work for
   someone who never saw the original.
4. Spread them across the week per founder-plan's posting mix, don't post
   them all at once.

## Rules

- No post should read as "watch the full video," the post is the content,
  not an ad for the source.
- If the source has an internal number (an unreleased metric mentioned
  live, say), it doesn't make it into any post unless it's already public.
- Credit the original source once, briefly, only if the user wants
  attribution (a podcast appearance, a talk); never required.

## Output

Three to five standalone post drafts pulled from the source, each labelled
with the moment it came from and which day of the week it fits per
founder-plan. Flag anything in the source that was private or off-the-
record and got excluded.
