# Founder Plan

The control room. Everything else in this personal set (founder-post,
founder-comment) executes what this decides. Run it once a week.

## Input

Ask for these if not already known:

1. Which venture this week's plan is for, and the user's actual seat
   there (employee-with-ownership vs. actual founder, see founder-post for
   the distinction), since that decides which voice is fair game.
2. What actually happened this week worth writing about: a call, a
   number, a mistake, a thing built, an argument had. This is where real
   posts come from, not a topic list.
3. Who the user wants to be visible to: a short list split into people
   with reach they can genuinely add value to, peers at the same level,
   and people who could actually fund, hire, or partner with them.

## What to post

Four posts a week beats seven; the fifth is almost always the weak one
that drags the average down. Mix across the week, never the same type
twice in a row:

| type | share | job |
| --- | --- | --- |
| **Proof** | 1/week | something real that happened, with a public number |
| **Opinion** | 1/week | a position that could cost some agreement |
| **Teach** | 1/week | one thing the reader can use today |
| **Story** | 1/fortnight | a scene with real stakes or cost |
| **Build-in-public** | as relevant | only for a venture the user actually founded |

For each slot: the real angle drawn from what happened this week (not a
topic), and which hook formula fits (see founder-post). Hand slots needing
a full draft to founder-post.

## When to post

Tuesday to Thursday, 7:30-9:30am in the audience's timezone (not the
user's, if they differ) is the default for a professional audience, with
Monday afternoon and Friday morning second tier. Weekends: personal-story
posts or nothing. State plainly that the hour matters far less than
whether the first line earns the second; don't let the user optimize
posting time before the hook actually works.

## Who to engage with

A list of 10, split three ways, tied to founder-comment's method:

- **5 reach**: people with an audience the user wants, whose posts they
  can genuinely add to. Comment before a post has 20 comments.
- **3 peers**: same level, same field, the group that reciprocates.
- **2 buyers or partners**: people who could actually fund, hire, or
  partner. Comment on their posts for weeks before any DM, never pitch in
  a comment.

20 minutes a day, before posting, not after. Hand the day's target posts
to founder-comment for real drafts.
