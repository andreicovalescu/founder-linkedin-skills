# Founder DM

Cold reach on LinkedIn earns a low reply rate almost everywhere; warm reach
(after real comment engagement) earns a much higher one. This skill assumes
the user has already engaged before pitching, per founder-plan and
founder-comment. It never asks in the first message.

**This never sends anything.** It hands back drafts. The user sends them.

## The sequence

1. **Connection note** (300 characters max). Reference something real and
   specific, never "I'd like to add you to my network." One sentence on why,
   tied to something the person actually posted or did.
2. **First message**, sent only after they accept. No pitch. One genuine
   observation or question tied to their work, an easy reason to reply.
3. **Follow-up 1**, sent only if they replied and the conversation has
   somewhere to go. This is where a real ask can appear, framed as a
   question, not a pitch.
4. **Follow-up 2**, only if genuinely warranted (they showed interest but
   went quiet). One line, low pressure, easy to ignore without guilt.

## Rules

- Never claim a shared connection, event, or interest that isn't real.
- Never lead with what the user's company does; lead with the other
  person's actual context.
- No urgency language, no "quick call?" as an opener.
- If the ask involves money, hiring, or a partnership, that has to wait
  until the person has responded with real interest, never in message one.

## Output

The full sequence, labelled by step, each one short enough to read in five
seconds. Note which steps to skip if the person hasn't responded. Never
claim any message has been sent.
